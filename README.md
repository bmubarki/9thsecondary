
# جواز السفر البيئي - المملكة العربية السعودية

🎮 **مشروع تفاعلي تعليمي** يستهدف طلاب وطالبات المدارس للتعرف على المحميات الطبيعية في المملكة العربية السعودية باستخدام التلعيب (Gamification).

## ✨ مميزات المشروع
- استكشاف أكثر من 20 محمية طبيعية سعودية.
- الإجابة على أسئلة تفاعلية للحصول على أختام رقمية.
- تخصيص اسم وصورة "المسافر البيئي".
- إمكانية تنزيل الجواز كصورة أو PDF.
- طباعة الجواز بتنسيق يشمل التاريخ، الشعار، والختم الرسمي.

## 🏫 المدرسة
**الثانوية التاسعة بمحافظة الخرج**  
بإشراف وزارة التعليم – المملكة العربية السعودية 🇸🇦

## 🚀 كيفية الاستخدام
1. افتح `index.html` مباشرة من المتصفح.
2. أجب على الأسئلة التفاعلية.
3. احصل على أختام المحميات.
4. بعد جمع الأختام، يمكنك:
   - طباعة الجواز.
   - تنزيله كصورة.
   - حفظه كملف PDF.

## 📄 ترخيص
مشروع تعليمي غير ربحي، مفتوح المصدر لأغراض التوعية البيئية والتعليمية فقط.
